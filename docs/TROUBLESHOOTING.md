# Stealtify — Решение проблем и ЧаВО

Распространённые проблемы и способы их решения. Полное руководство смотрите в
[USER_GUIDE.md](./USER_GUIDE.md).

---

## Установка

**APK не устанавливается.**
- Разрешите **установку из неизвестных источников** для вашего браузера/файлового менеджера.
- Архитектурная поддержка зависит от флейвора:
  - **mobile**: только **arm64-v8a** (телефоны 64-бит)
  - **tv**: **arm64-v8a + armeabi-v7a + x86** (Android TV, включая 32-битные приставки и эмуляторы)
- Требуется **Android 10+** (API 29+). Оно не установится на старые версии Android.
- Если уже установлена версия с другой подписью (например, старая сборка из другого источника), сначала удалите её.

**Не устанавливается откатанная (старая) версия.**
- Android отказывается устанавливать версию с меньшим `versionCode` поверх версии с большим. Сначала полностью удалите текущее приложение (это сотрёт настройки и БД — экспортируйте резервную копию перед этим через Settings → Data → Export).

## Подключение

**Ничего не происходит при нажатии Connect / нет диалога разрешения VPN.**
- Предоставьте разрешение VPN, когда Android его запросит. Одновременно может быть активен только **один** VPN — сначала отключите любое другое VPN-приложение.
- Добавьте хотя бы один прокси-сервер во вкладке **Proxies** перед подключением.

**"All proxies unavailable. Check your connection."**
- Протестируйте каждый сервер: Proxies → нажмите значок **Test** (обновить). Исправьте все, которые не работают.
- Проверьте хост/порт/учётные данные и убедитесь, что базовое подключение в интернет работает.
- Если вы используете Failover, порог задержки (Settings → Connection) может быть слишком строгим — поднимите его или отключите Failover для тестирования.

**Подключен, но интернета нет.**
- Выбранный/используемый по умолчанию прокси может быть недоступен — проверьте плитку **Proxies (check)** и выберите доступный сервер.
- Если у конкретного приложения нет интернета, его прокси группы может быть неработающим; переназначьте приложение на работающую группу или установите **No group** (прямое подключение) для подтверждения.

## Маршрутизация (приложения/сайты идут неправильно)

**Конкретное приложение по-прежнему использует мой реальный IP / не проксируется.**
- По умолчанию трафик **без совпадающего правила идёт прямо**. Назначьте приложение группе, которая имеет работающий прокси (Rules → App rule, или добавьте приложение в группу).
- Убедитесь, что группа **включена** и на самом деле имеет прокси (не "No proxy / direct").

**Веб-сайт игнорирует моё правило домена.**
- Правила для доменов соответствуют TLS SNI/имени хоста. Используйте правильный формат: `example.com`, `mail.example.com` или подстановочный `*.example.com`.
- Некоторые приложения используют хардкодированные IP или DoH, которые обходят совпадение доменов — в этом случае маршрутизируйте само приложение.

**Утечка DNS/IP.**
- Включите **Settings → DNS → DNS leak protection**.
- Убедитесь, что для соответствующего приложения/домена действительно есть правило; немаршрутизированный трафик идёт прямо по замыслу.

## Kill Switch

**Интернет заблокирован после отключения / VPN выпал.**
- Это работает **Kill Switch** (Settings → Security). Переподключитесь или отключите Kill Switch.
- Для надёжной блокировки на уровне системы также включите **Always-on VPN** и **Block connections without VPN** в системных настройках VPN Android (приложение ведёт туда).

## Фоновый режим / загрузка

**VPN выпадает, когда экран выключен или приложение в фоне.**
- Исключите Stealtify из **оптимизации батареи** (Android Settings → Apps → Stealtify → Battery → Unrestricted).
- Включите **Settings → Connection → Auto-reconnect**.

**Автозапуск при загрузке не работает.**
- Включите **Settings → Connection → Auto-start on boot**.
- На некоторых устройствах OEM (Xiaomi/MIUI, Huawei, Oppo, Samsung) вы также должны разрешить **Autostart** и отключить агрессивное управление батареей в системных настройках.

## Импорт / подписки / QR

**Импорт подписки не удаётся или возвращает 0 серверов.**
- Убедитесь, что URL — это действительная конечная точка подписки (`http(s)://…` с путём).
- Некоторые провайдеры проверяют личность клиента: попробуйте **User-Agent preset** и/или переген​ерируйте **HWID** в секретном меню (Settings → тройной тап по версии).
- Подтвердите, что ссылка не истекла и ваша сеть может её достичь.

**QR-сканирование ничего не делает.**
- Разрешите разрешение **camera**; убедитесь в хорошем освещении и чётком коде.
- Слишком большие коды (>8 KB) и неизвестные схемы URI отклоняются в целях безопасности.

**Вставленная ссылка на прокси не распознана.**
- Используйте поддерживаемую схему (`socks5://`, `http://`, `ss://`, `vless://`, `vmess://`, `trojan://`, `awg://`, `vpn://`). Для необычных конфигов используйте **Advanced input**.

## Специфичные протоколы

**VLESS/VMess/Trojan (TLS/REALITY) не подключаются.**
- Дважды проверьте UUID, **SNI**, **fingerprint**, **flow** и транспорт (tcp/ws/grpc) в соответствии с тем, чего ожидает сервер.
- Переключите **Use TLS** согласно требованиям сервера.
- REALITY/TLS чувствительны ко времени — убедитесь, что часы на устройстве правильно выставлены.

**Shadowsocks подключается, но данные не идут.**
- Проверьте, что **метод шифрования** соответствует серверу (например `aes-256-gcm`, `chacha20-poly1305`).

## Обновления и уведомления

**Запрос на обновление постоянно появляется / обновление не удаётся.**
- Убедитесь, что устройство может достичь конечной точки обновления. Если автообновление не удаётся, загрузите последний APK вручную и установите его поверх текущего.
- Обязательные обновления по замыслу невозможно отложить.

**Статистика трафика не отображается в уведомлении.**
- Включите разрешение **notification** (Settings → Notifications → Traffic statistics; приложение предложит открыть системные настройки, если потребуется).

## Резервная копия

**Импорт ничего не изменил.**
- Импорт **объединяет** с текущей конфигурацией (не перезаписывает её). Проверьте наличие дубликатов и перезагрузите приложение, если UI не обновился.
- JSON резервной копии содержит секреты — храните его в тайне.

## Всё ещё застрял?

Включите **connection logging** (Settings → Security) для захвата событий, затем свяжитесь со **support@stealtify.app** или откройте issue. **Отредактируйте IP-адреса, имена хостов и учётные данные** во всём, что вы делитесь. Для вопросов безопасности используйте соответствующую процедуру вместо публичного отчёта.

# Stealtify — Руководство пользователя

Полная инструкция по всему функционалу приложения.

Stealtify — это Android-приложение (userspace VPN), которое пропускает трафик отдельных приложений и доменов через прокси-серверы. Поддерживаются протоколы **SOCKS5, HTTP, Shadowsocks, SSH, VLESS, VMess, Trojan и AmneziaWG**. Работает на Android 10+ (arm64).

## 1. Быстрый старт

1. Откройте приложение — вы попадёте на **Главную**.
2. Перейдите на вкладку **Прокси** (внизу) и добавьте хотя бы один сервер (кнопка **+**, QR-код или ссылка-подписка).
3. Вернитесь на **Главную** и нажмите большую круглую кнопку **Подключить**.
4. При первом подключении Android попросит разрешение на VPN — подтвердите.
5. Статус сменится на **«Защищено»**, начнёт идти статистика трафика.

По умолчанию (если правила не настроены) весь трафик идёт через **прокси по умолчанию**. Используйте **Правила** и **Группы**, чтобы направить через прокси только выбранные приложения/сайты или, наоборот, отправить часть трафика напрямую (см. разделы 4–5).

Нижняя панель навигации содержит 4 вкладки: **Главная**, **Прокси**, **Правила**, **Настройки**. Экран **Приложения** открывается из раздела «Правила», а также по нажатию на цифру «Правил» в плитке быстрой статистики на Главном экране.

## 2. Главный экран (Дашборд)

Центральный экран управления подключением и мониторинга.

### Кнопка подключения
- Большая круглая кнопка в центре: **Подключить** / **Отключить**.
- Над ней — индикатор состояния: **«Защищено»**, **«Не подключено»** или **«Переподключение...»**.
- Если не добавлено ни одного прокси, при нажатии появится красная карточка-подсказка и снэкбар «Сначала добавьте прокси-сервер во вкладке Прокси». Если проверка доступности показала, что все серверы недоступны, вместо этого появится снэкбар «Все прокси недоступны. Проверьте подключение.».

### Настраиваемые плитки
Иконка редактирования **«Настроить плитки»** в правом верхнем углу включает режим редактирования плиток: их можно **перетаскивать** (долгое нажатие + перетаскивание), **скрывать/показывать** (значок глаза), менять порядок стрелками вверх/вниз или сбросить кнопкой **«Сбросить по умолчанию»**. Доступны 6 плиток:

| Плитка | Что показывает |
|--------|----------------|
| **Скорость** | Два индикатора — «Прокси» и «Напрямую», у каждого скорость загрузки ↓ и отдачи ↑, обновление раз в секунду, показывается только при активном подключении |
| **Внешний IP** | Флаг/страна и имя сервера, с кнопкой обновления; показывается только при активном подключении. Страна определяется через ipapi.co |
| **Быстрая статистика** | «Серверов» (активных), «Пинг, мс» (лучший), «Правил» (активных) — нажатие работает только на «Правил» и ведёт на экран «Приложения» |
| **Прокси (проверка)** | Список серверов со статусом доступности (зелёный/красный), пингом и типом. Нажатие на строку делает этот сервер **сервером по умолчанию** и перезапускает туннель, если он активен (пауза ~1 с); есть кнопка перепроверки |
| **Трафик** | Суммарный трафик за сессию, полоса «N% прокси / N% напрямую», длительность сессии, число активных соединений, счётчик заблокированных DNS |
| **Приложения по трафику** | Топ‑5 приложений по объёму трафика (прокси/напрямую/всего) плюс «и ещё N приложений» |

### Уведомление об обновлении
Если доступна новая версия, при открытии появится диалог с номером версии и списком изменений: **Обновить** или **Позже**. Обязательные обновления отложить нельзя. Тот же диалог показывает прогресс скачивания после старта обновления, кнопку **«Установить»** и элементы повтора/отмены; загрузка продолжается в фоне через уведомление foreground-сервиса, даже если вы свернёте приложение.

## 3. Прокси-серверы

Вкладка **Прокси** — управление серверами. Пустой список показывает подсказку «Нажмите + чтобы добавить».

### Поддерживаемые протоколы
`SOCKS5` · `HTTP` · `Shadowsocks` · `SSH` · `VLESS` · `VMess` · `Trojan` · `AmneziaWG`

### Способы добавить сервер

**A. Кнопка + (быстрое добавление)**
Открывает полноэкранный диалог **«Добавить»** с единственным полем **«Прокси или подписка»**, куда можно вставить:
- ссылку прокси в любом формате (см. ниже) — просто `host:port` без схемы распознаётся как SOCKS5, а `http(s)://host:port` без пути — как HTTP-прокси,
- либо URL-подписку (URL с путём) — определяется автоматически, импортируются все серверы из неё.
Поле имени опционально (по умолчанию — «Тип host», например «VMess example.com»). Кнопка **«Расширенный ввод»** открывает полный редактор со всеми полями протокола. Кнопка **«Обновить все»** обновляет сразу все подписки.

**B. QR-сканер** (иконка камеры вверху)
Наводите камеру на QR-код — распознаются как ссылки прокси, так и ссылки-подписки; после сканирования появляется карточка-подтверждение с кнопками **Добавить / Импортировать / Пропустить**. Сканер также распознаёт QR-код передачи с телевизора (`stealtify://…`, см. руководство для TV). Есть переключатель фонарика. Требуется разрешение на камеру.

**C. Подписка по URL**
Вставьте ссылку-подписку в поле быстрого добавления. Приложение скачает список серверов и покажет диалог «Подписка импортирована»: «Добавлено прокси: N».

### Поддерживаемые форматы ссылок
Распознаваемые схемы: `socks5://`, `socks://`, `http://`, `https://` (host:port без пути — HTTP-прокси; с путём — подписка), `ss://`, `shadowsocks://`, `vless://`, `vmess://`, `trojan://`, `awg://`, `vpn://` (формат AmneziaVPN), `ssh://`, а также просто `host:port` (распознаётся как SOCKS5). Схема `wg://` **не поддерживается**. Подписка может быть простым списком ссылок или конфигом xray в формате JSON.

### Действия с сервером
На карточке каждого сервера — три иконки, меню «⋮» и переключателя включения/выключения нет:
- **Проверить** — полное установление соединения по протоколу плюс запрос внешнего IP (таймаут 7 с); показывает задержку или ошибку.
- **Редактировать** (шестерёнка) — открывает расширенный редактор.
- **Поделиться** — открывает экран с QR-кодом и кнопкой **«Скопировать ссылку»** для копирования в буфер обмена; сам текст ссылки на экране не показывается, а запись в буфере помечена как чувствительная. Перед показом QR-кода выводится диалог-предупреждение «Ссылка содержит учётные данные» с кнопками **Показать / Отмена** — ссылка содержит пароли и ключи доступа к серверу, поэтому передавайте её только доверенным людям.

**Удаления на карточке нет.** Оно находится внутри расширенного редактора: кнопка **«Удалить прокси»** внизу открывает подтверждение («Удалить прокси?» … «Это действие нельзя отменить»).

### Расширенный редактор
Базовые поля: имя, тип протокола (8 типов), хост, порт (автоматически подставляется значение по умолчанию для типа: 1080/8080/8388/22/443/443/443/51820), логин/пароль с кнопкой-«глазом» — показываются только для **SOCKS5, HTTP, Shadowsocks и SSH** — и выпадающий список **«Цепочка через прокси»**. В зависимости от протокола появляются дополнительные поля:
- **VLESS:** UUID; Security none/tls/reality; Transport tcp/ws/grpc/httpupgrade/mkcp/quic/splithttp; Flow (xtls-rprx-vision); SNI; Fingerprint (chrome, firefox, safari, ios, android, edge, 360, qq, random, randomized); ALPN; Reality Public Key / Short ID / SpiderX; WS Path/Host; gRPC Service Name; Header Type; заголовок mKCP + seed; QUIC security/key/header; SplitHTTP path/host; «Мультиплексирование (mux)» с concurrency 1–16; «Фрагментация TLS» с длиной/интервалом.
- **VMess:** UUID, Alter ID, Security auto/aes-128-gcm/chacha20-poly1305/none, те же 7 транспортов, SNI, Fingerprint, ALPN, WS Path/Host, gRPC Service Name, Header Type. Reality отсутствует.
- **Trojan:** Пароль (обязателен), Transport (7 вариантов), Security tls/reality, SNI, Fingerprint, ALPN, поля Reality, поля WS/gRPC.
- **Shadowsocks:** метод шифрования — aes-256-gcm, aes-192-gcm, aes-128-gcm, chacha20-ietf-poly1305, xchacha20-ietf-poly1305 (без SS-2022 и без plain); пароль берётся из общего поля пароля.
- **SSH:** Host Key Fingerprint (фиксируется автоматически при первом подключении), Шифр (опционально). Только парольная аутентификация — входа по ключу нет.
- **AmneziaWG:** Private Key, Peer Public Key, Preshared Key, Адрес клиента (10.0.0.2/32), DNS (1.1.1.1), MTU (1280), Keepalive (25), а также параметры обфускации Jc/Jmin/Jmax, S1/S2, H1–H4, I1–I5 (полей S3/S4 нет).

**Цепочка (chain):** работает, когда внешним (последним) звеном цепочки является SOCKS5, HTTP, VLESS, VMess или Trojan. SSH, AmneziaWG и Shadowsocks не могут быть внешним звеном (настройка цепочки для них игнорируется), но могут быть внутренним звеном. Глубина цепочки — до 5.

### Подписки
Серверы из одной подписки группируются под свёрнутой строкой-заголовком, где показаны название подписки (или «Подписка»), «N прокси», кнопка обновления и кнопка удаления (с подтверждением). По нажатию строка разворачивается и показывает использованный/общий трафик (%) с прогресс-баром, который краснеет выше 90%, «безлимит» при отсутствии лимита, «Действует до» / «Истекла» и URL подписки (нажатие копирует его).

**Автообновление подписок:** список серверов обновляется в фоне автоматически, примерно раз в 12 часов при наличии сети. Точный момент выбирает система, поэтому интервал может быть и больше. Открытие приложения или подключение VPN обновление не запускают — для немедленного обновления нажмите **Обновить** на карточке подписки.

При каждом обновлении серверы подписки **заменяются целиком**: старые удаляются, новые добавляются заново. Поэтому ручные правки серверов из подписки не сохраняются, а группа, привязанная к серверу подписки, после обновления теряет эту привязку и становится «Без прокси (напрямую)». Отключить автообновление или изменить период в настройках нельзя.

## 4. Правила и группы

Вкладка **Правила** — это **группы маршрутизации**. Группа объединяет приложения и/или домены и (опционально) привязывается к прокси. Если прокси не выбран — трафик группы идёт **напрямую**.

Кнопка **+** вверху предлагает:
- **Новая группа**
- **Правило для приложения** (переход к экрану «Приложения»)

### Создание группы
- Введите имя (например, «Видео», «Соцсети», «Работа»).
- Выберите прокси из списка или «Без прокси (напрямую)».

### Карточка группы
Показывает:
- Имя и переключатель **включена/выключена**. Когда переключатель выключен, карточка показывает «Выключена — не маршрутизируется».
- Прокси группы — `ТИП · host:port` — либо «Без прокси (напрямую)».
- Резервную группу, если задана: «Резерв: <Группа> (<имя сервера>)».
- Списки **Домены** и **Приложения** с возможностью удалить каждый элемент (крестик).

### Управление группой (меню ⋮ → полноэкранный редактор **«Редактирование правила»**)
- **Переименовать** — поле названия и кнопка ОК.
- **Выбрать прокси** для группы.
- **Резервная (fallback) группа** — выпадающий список, по умолчанию «Без резерва»; если прокси группы недоступен или медленный, трафик пойдёт через резервную группу.
- **Добавить приложение** — поиск с чипами **Все / Установленные / Системные**, по умолчанию «Установленные».
- **Добавить домен** (подсказка: youtube.com, *.google.com, mail.ru) — принимаются только две формы: `example.com` соответствует самому домену и всем его поддоменам, `*.example.com` — только поддоменам. Отдельного переключателя «точный/поддомен/маска» нет. При неверном формате — ошибка «Неверный формат домена».
- **Удалить правило** — с подтверждением: «Группа «name» и все её правила будут удалены.».

## 5. Правила приложений

Экран **«Правила приложений»** — открывается из «Правил» → «Правило для приложения», а также по нажатию на «Правил» в плитке быстрой статистики на Главном экране. Позволяет назначить каждому приложению группу.

- **Поиск** по названию.
- **Фильтры** (чипы): Все / Установленные / Системные, по умолчанию Установленные.
- Нажатие на карточку приложения открывает выпадающий список:
  - **Без группы** — приложение работает напрямую (без прокси);
  - либо любая из созданных групп.
- Выбор сохраняется автоматически.

> Приложения назначаются на **группы**, а не на прокси напрямую. Прокси задаётся у группы — так одну настройку прокси можно переиспользовать для многих приложений.

## 6. Настройки

Настройки разложены по 7 категориям-папкам. Внизу экрана также есть «Связаться с нами» и номер версии.

### Внешний вид
- **Тёмная тема** — переключатель тёмного/светлого оформления, по умолчанию включена. Опции «следовать теме системы» нет.

### Безопасность
- **Kill Switch** — по умолчанию выключен. При разрыве сети или во время переподключения приложение держит VPN-интерфейс открытым, но не пропускает трафик — так ничего не утекает, пока приложение живо. Системную блокировку Android (VPN lockdown) он не использует — если приложение или его сервис завершены, защита прекращается. Для гарантии на уровне ОС приложение показывает подсказку «Для надёжной защиты включите Always-on VPN в системных настройках» с кнопкой-переходом **VPN** — там же стоит включить и **Always-on VPN**, и **Блокировать соединения без VPN**.
- **Логирование соединений** — по умолчанию выключено; записывает события подключения и ошибки. При включении появляется кнопка **«Посмотреть логи»**.

### DNS
- **Защита от утечек DNS** — DNS-запросы только через VPN-туннель (по умолчанию включено). Весь DNS-трафик приложений перехватывается (порт 53); когда активны правила доменов или DNS-фильтрация, DoT/DoH других приложений (порт 853, известные IP DoH) тоже блокируется, чтобы правила доменов продолжали работать.
- **DNS-фильтрация** — блокировка рекламы и трекеров через DNS; по умолчанию выключена. Использует **встроенный список примерно из 90 доменов**, зашитый в приложение — он не скачивается и не обновляется по сети.
- **DNS-серверы** — выбор провайдера одним списком из 9 пресетов. Пункты с замком 🔒 шифруют запросы, обычные — нет:
  - Cloudflare (1.1.1.1) — по умолчанию,
  - Cloudflare · DoT 🔒 и Cloudflare · DoH 🔒,
  - Google (8.8.8.8) и Google · DoT 🔒,
  - AdGuard (94.140.14.14) и AdGuard · DoT 🔒,
  - Quad9 · DoT 🔒,
  - **Свои DNS** — поля DNS 1 (основной) и DNS 2 (резервный). Принимаются форматы: обычный IP (`9.9.9.9`), `tls://9.9.9.9#dns.quad9.net` или `https://dns.quad9.net/dns-query#9.9.9.9` — IP-адрес обязателен, одно только имя хоста отклоняется. Кнопка **«Сохранить DNS»** применяет выбор, после чего приложение предложит переподключиться.

  DoT (DNS-over-TLS) и DoH (DNS-over-HTTPS) скрывают от провайдера, какие сайты вы открываете. Зашифрованные DNS-запросы идут через прокси по умолчанию, а результаты учитывают TTL записи.
- **Только шифрованный DNS** — по умолчанию выключено. Обычно у шифрованных пресетов есть запасной незашифрованный вариант: если провайдер заблокирует DoT/DoH, запросы тихо пойдут в открытом виде. С этой настройкой запасной вариант убирается — при блокировке резолвинг откажет, но открытых запросов не будет; событие отката в открытый DNS логируется как «Шифрованный DNS недоступен — откат на обычный DNS», когда эта настройка выключена и происходит откат.

### Соединение
- **Автопереподключение** — восстанавливать соединение при смене сети (по умолчанию включено).
- **Автозапуск при загрузке** — по умолчанию выключено; запускает VPN автоматически после перезагрузки устройства, но только если разрешение на VPN уже было выдано ранее.
- **Failover прокси** — по умолчанию выключено. Если включить, проверяет прокси перед подключением (а также при каждом открытии Главного экрана) и переключается на резерв при недоступности. Регулируется ползунком **«Порог задержки»** от 500 мс до 30 с, по умолчанию 3 с: если задержка выше или проверка не прошла — используется резервная группа. Проверка — это TCP-подключение к host:port (для AmneziaWG — UDP-проба), с ограничением 10 с. Важно: **сам прокси по умолчанию автоматически не переключается** — если он недоступен, соединения через него просто не устанавливаются.

### Уведомления
- **Статистика трафика** — по умолчанию выключено; показывать скорости proxy/direct в уведомлении VPN. При включении, если системные уведомления отключены, приложение запросит разрешение на уведомления.

### Данные
- **Бэкап конфигурации** — экспорт/импорт прокси, правил и настроек.
  - **Экспорт** — сохраняет всю конфигурацию в файл `stealtify_backup.stbackup` (через системный выбор файла), зашифрованный ключом, встроенным в приложение, а не паролем, который задаёте вы — это защищает от случайного прочтения, но не от того, у кого есть само приложение. Файл содержит ваши прокси **вместе с паролями и ключами**, группы, правила приложений и правила доменов, а также две настройки (тёмная тема, автопереподключение); относитесь к файлу как к секрету. Старый формат JSON всё ещё поддерживается при импорте.
  - **Импорт** — ⚠️ **ВНИМАНИЕ:** системный выбор файла открывается сразу, и после выбора файла происходит полная ЗАМЕНА всей текущей конфигурации новой (прокси, правила, группы) **немедленно, без диалога подтверждения**. Старая конфигурация удаляется. Сначала сделайте экспорт, если хотите сохранить текущее состояние.

### Обновления
- **«Проверить обновления»** — показывает текущую/доступную версию. Проверяется автоматически при открытии Главного экрана и вручную кнопкой **«Проверить»** в этой карточке — периодической фоновой проверки нет. Кнопка меняется между **Проверить / Обновить / Установить / Повторить**, во время загрузки доступна **Отмена**.

### Внизу экрана
- **«Связаться с нами»** — письмо на support@stealtify.app.
- **Версия** приложения, например «Stealtify 1.0.0 (108)».

## 7. Логи соединений

Открывается из Настройки → Безопасность → «Посмотреть логи» (когда логирование включено).

- Показывает 8 типов событий: подключение, отключение, ошибка, DNS-запрос, смена сети, Kill Switch, переподключение и проверка обновлений — каждое со своей иконкой и цветом. Фильтра нет.
- У записи: время (ЧЧ:ММ:СС), текст и опциональные детали.
- Счётчик показывает «N записей». Кнопка очистки (корзина) отображается только при наличии записей и удаляет их все. Логи хранятся в памяти (не более 500 записей) и теряются при перезапуске.

## 8. Как работает маршрутизация

Для каждого соединения решение принимается по приоритету:

1. **Правило приложения** → группа приложения и её прокси (например, YouTube → группа «Видео» → её прокси). Группа «Без прокси (напрямую)» отправляет трафик приложения напрямую, минуя VPN-интерфейс полностью.
2. **Правило домена** → прокси его группы или напрямую. Домен определяется по DNS-ответам приложения или по TLS SNI на порту 443 (например, `youtube.com` → группа «Видео»).
3. Если хотя бы одно правило домена существует, но ни одно не подошло для этого соединения → **напрямую**.
4. **Локальные/LAN-адреса, link-local, loopback и multicast** → напрямую. Эта проверка выполняется только после шагов 1–3, поэтому явное правило приложения всё равно направит LAN-трафик через прокси, если вы так настроили.
5. Иначе → **прокси по умолчанию** (сервер, выбранный в плитке «Прокси (проверка)» на Главном экране, либо первый активный сервер, если выбор не сделан).

Итог: если правила вообще не заданы, **весь трафик идёт через прокси по умолчанию** — напрямую он не отправляется. Используйте Правила/Группы, чтобы выделить приложения или домены, которым нужен прямой доступ или другой прокси.

Дополнительно: **цепочки прокси** (трафик проходит через несколько серверов), **failover** по задержке (сам прокси по умолчанию автоматически не переключается) и **Kill Switch**, который держит VPN-интерфейс открытым без пропуска трафика, пока сеть недоступна или идёт переподключение.

## 9. Типовые сценарии

**Подключиться к VPN**
Главная → кнопка **Подключить** → подтвердить разрешение VPN (при первом запуске).

**Добавить прокси вручную**
Прокси → **+** → вставить ссылку/данные → (при необходимости «Расширенный ввод») → **Добавить**.

**Импорт по QR**
Прокси → иконка камеры → навести на QR.

**Импорт подписки**
Прокси → **+** → вставить URL-подписку → «Добавлено прокси: N».

**Направить приложение через прокси**
Правила → создать группу с прокси → Приложения → выбрать приложению эту группу.
(Либо добавить приложение прямо в группу через её меню.)

**Направить сайт через прокси**
Правила → открыть/создать группу → добавить домен (`example.com` или `*.example.com`).

**Выбрать сервер по умолчанию**
Главная → плитка **«Прокси (проверка)»** → нажмите на строку, чтобы сделать сервер сервером по умолчанию.

**Удалить прокси**
Прокси → откройте редактор сервера (**Редактировать**) → **«Удалить прокси»** внизу → подтвердите.

**Настроить резерв при сбое прокси**
Настройки → Соединение → включить **Failover**, задать порог задержки. Для группы задать **резервную группу**.

**Включить Kill Switch**
Настройки → Безопасность → **Kill Switch** (рекомендуется также включить Always-on VPN в системе).

**Сделать бэкап / восстановить**
Настройки → Данные → **Экспорт** (сохранит `stealtify_backup.stbackup`) / **Импорт** (сразу открывает выбор файла и заменяет всю конфигурацию, как только файл выбран, без подтверждения — предварительно сделайте бэкап!).

## 10. Разрешения приложения

- **VPN-сервис** — основная функция (перехват трафика), работает как foreground-сервис (используется также для загрузки обновлений).
- **Камера** — сканирование QR-кодов.
- **Уведомления** — статистика в шторке и статус работы.
- **Разрешения на доступ к файлам нет** — экспорт/импорт используют системный выбор файла.
- **Установка пакетов** — установка скачанных обновлений.
- **Список установленных приложений** — построение списка приложений для правил.
- **Состояние сети** — автопереподключение и автозапуск.
- **Загрузка устройства** — автозапуск при загрузке (если включён и разрешение уже было выдано ранее).

### Сетевые обращения самого приложения

В приложении нет аналитики, сбора крашей и учётной записи. Помимо ваших прокси-серверов, приложение обращается к:

- **update.stealtify.app** — при открытии Главного экрана, при ручной проверке обновлений и при скачивании APK во время обновления.
- **ipapi.co** — для определения страны в плитке «Внешний IP»; этот запрос отправляется **напрямую, в обход прокси**, поэтому данный сервис видит ваш настоящий внешний IP.
- **api.ipify.org**, **ifconfig.me**, **icanhazip.com** — сервисы определения внешнего IP при проверке сервера кнопкой «Проверить»; эти запросы идут **через проверяемый прокси**.
- **Ссылки ваших подписок** — каждый запрос содержит случайный идентификатор установки в заголовке (`X-Hwid`) и User-Agent.
- **Выбранные вами DNS-серверы** в Настройках.

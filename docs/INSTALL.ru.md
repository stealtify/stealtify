# Stealtify 1.0.0

**Stealtify** пропускает трафик выбранных приложений и сайтов через ваши прокси-серверы.
Без root. Поддерживает SOCKS5, HTTP, Shadowsocks, SSH, VLESS, VMess, Trojan и AmneziaWG.

> 📘 Полная инструкция по всем функциям — в файле **[USER_GUIDE.ru.md](USER_GUIDE.ru.md)** рядом с этим файлом.
> 🇬🇧 English version: **[INSTALL.md](INSTALL.md)**.

---

## Об этом релизе

Это **первый публичный релиз** Stealtify.

Всё работает на устройстве через стандартный Android VpnService API — без root,
без регистрации и без телеметрии. Прокси-серверы вы предоставляете сами,
а приложение решает, какие программы и сайты пойдут через них, а какие — напрямую.
Помимо ваших собственных прокси-серверов, приложение обращается только к
серверу обновлений, сервису геолокации по IP ipapi.co (для страны на Главном
экране — этот запрос идёт напрямую, в обход прокси), сервисам определения
внешнего IP через прокси во время проверки серверов, а также к серверам
подписок и DNS, которые вы указали. Подробности — в USER_GUIDE.ru.md, раздел 10.

Коротко: маршрутизация по приложениям и доменам, 8 протоколов, импорт по ссылке /
QR-коду / подписке, Kill Switch и защита от утечек DNS, IPv4 + IPv6, статистика
трафика и резервные серверы. Полный список возможностей — ниже и в
[USER_GUIDE.ru.md](USER_GUIDE.ru.md).

## Требования

- Android **10** и новее.
- Процессор **arm64** (большинство современных телефонов).
- Хотя бы один прокси-сервер (данные вам предоставляет ваш провайдер прокси/VPN — ссылка, QR-код или подписка).
- Язык интерфейса: русский.

## Установка

> ⚠️ **Если ранее была установлена тестовая сборка:** Android не позволяет установить релизную сборку поверх debug-версии из-за разных ключей подписи. Нужно сначала удалить старую версию. **Перед удалением сделайте резервную копию** в приложении (**Настройки → Данные → Экспорт**), затем восстановите её после установки — иначе прокси и правила будут потеряны.

1. Скачайте файл **`Stealtify_1.0.0_release.apk`**.
2. Откройте его. Если Android попросит — разрешите **установку из неизвестных источников** для браузера или файлового менеджера.
3. Нажмите **Установить** и откройте приложение.

Дальнейшие обновления приложение находит само: на Главном экране и в разделе
**Настройки → Обновления** появится предложение обновиться.

### Проверка целостности файла (по желанию)

К каждой сборке публикуется контрольная сумма SHA-256. Чтобы убедиться, что файл не повреждён:

```powershell
Get-FileHash .\Stealtify_1.0.0_release.apk -Algorithm SHA256
```

Полученное значение должно совпасть с суммой, указанной для этой версии.

### Защита от поддельных сборок

Контрольная сумма подтверждает только то, что файл скачался без повреждений. Она ничего
не говорит о том, **кто его собрал**: кто угодно может пересобрать APK, прописать в нём свои
серверы, выложить под именем Stealtify и опубликовать рядом свою контрольную сумму. Для
VPN-приложения это и есть главная угроза — поддельная сборка видит весь ваш трафик.

Stealtify защищается от этого сам. Каждая настоящая сборка подписана ключом разработчика,
и при запуске приложение проверяет эту подпись. Поддельная сборка такую подпись получить
не может: при пересборке она становится другой, а закрытый ключ разработчика в APK не хранится.

Если проверка не прошла, вместо интерфейса приложение показывает экран с предупреждением,
что копия неподлинная, и ссылку на официальный источник; настройки и кнопка подключения
недоступны. Закрыть это предупреждение изнутри приложения нельзя: доступа к VPN и настройкам
нет, поэтому поддельная сборка не сможет пустить ваш трафик через чужой сервер.

Делать для этого ничего не нужно — проверка работает автоматически. Достаточно скачивать
приложение из официального источника:

- **https://stealtify.app** (сайт)
- **https://update.stealtify.app**

Надёжнее всего обновляться прямо из приложения: встроенное обновление скачивается по
защищённому соединению с закреплённым сертификатом, а его контрольная сумма проверяется
перед установкой.

## Быстрый старт

1. **Добавьте прокси.** Вкладка **Прокси** → кнопка **＋**. Вставьте ссылку прокси или ссылку-подписку. Либо нажмите иконку **камеры** и отсканируйте QR-код.
2. **Подключитесь.** Вкладка **Главная** → большая круглая кнопка **Подключить**. При первом запуске подтвердите разрешение на VPN.
3. Готово — статус сменится на **VPN активен**, начнёт идти статистика трафика.

По умолчанию через прокси идёт весь трафик. Чтобы направлять через прокси только
определённые приложения или сайты — настройте **Правила** и **Группы**
(подробно описано в [USER_GUIDE.ru.md](USER_GUIDE.ru.md)).

## Что умеет приложение (кратко)

- 🎯 **Маршрутизация по приложениям** — разным приложениям можно назначить разные прокси (через группы).
- 🌐 **Маршрутизация по доменам** — правила для сайтов, включая маски `*.example.com`.
- 🔗 **8 протоколов** — SOCKS5, HTTP, Shadowsocks, SSH, VLESS (Reality, XTLS-Vision), VMess, Trojan, AmneziaWG.
- 🌍 **IPv4 и IPv6** — включая сети только с IPv6.
- 📥 **Импорт** — вручную, по QR-коду или по ссылке-подписке (с автообновлением списка серверов каждые ~12 часов). Поделиться прокси через QR или копирование ссылки.
- 📊 **Мониторинг** — скорость, внешний IP, трафик по приложениям, проверка доступности серверов, журнал подключений.
- 🛡 **Безопасность** — Kill Switch, защита от утечек DNS, шифрованный DNS (DoT/DoH), блокировка рекламы через DNS, зашифрованное хранение данных прокси.
- ⚙ **Удобство** — тёмная тема, автозапуск при загрузке, автопереподключение, резервные серверы (failover), плитка в быстрых настройках, бэкап конфигурации (.stbackup; файл содержит ваши ключи — храните его в тайне).

## Известные ограничения

| Ограничение | Описание |
|---|---|
| **Конфликт подписей** | Android не позволяет установить APK, подписанный другим ключом, поверх уже установленного приложения. Если ранее была установлена тестовая (debug) сборка, нужно удалить её, а перед удалением сделать резервную копию конфигурации в приложении (**Настройки → Данные → Экспорт**), затем восстановить её после установки официальной сборки — иначе прокси и правила будут потеряны. |
| **Нет в Google Play** | Приложение распространяется только с https://update.stealtify.app. Android попросит разрешить установку из «неизвестных источников», так как приложение не из Play Маркета. |
| **Сборки старше 1.41.0 не обновляются** | Из-за изменения пиннинга сертификатов Let's Encrypt старые сборки не могут проверить сертификат сервера обновлений и не могут скачать обновления по сети. Скачайте и установите последний APK вручную с официального сайта. Конфигурация и данные сохранятся — ключ подписи тот же. |
| **Только русский интерфейс** | В приложении нет перевода на английский (или другой язык) и нет переключателя языка. |
| **Импорт бэкапа сразу заменяет конфигурацию** | Импорт файла `.stbackup` (или устаревшего JSON) сразу заменяет все прокси, группы и правила без подтверждения — если хотите сохранить текущую конфигурацию, сначала сделайте экспорт. |

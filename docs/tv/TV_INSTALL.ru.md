# Stealtify TV — установка

**Stealtify TV** пропускает трафик Android TV-приставки через ваши прокси-серверы.
Без root. Поддерживает SOCKS5, HTTP, Shadowsocks, SSH, VLESS, VMess, Trojan и AmneziaWG.

> 📘 Что умеет версия для телевизора и чем отличается от телефонной — в файле
> **[TV_USER_GUIDE.ru.md](TV_USER_GUIDE.ru.md)** рядом с этим файлом.
> 🇬🇧 English version: **[TV_INSTALL.md](TV_INSTALL.md)**.

---

> ⚠️ **Stealtify TV — бета.**
> Поддержка Android TV в активной разработке. Возможны нестабильная работа
> и изменения интерфейса между версиями.
> Нашли проблему — заведите Issue с меткой `tv`, указав модель приставки,
> версию Android и разрядность (см. [Какую сборку скачивать](#какую-сборку-скачивать)).

## Требования

- Android TV / Google TV **10** и новее.
- Приставка, телевизор со встроенным Android TV или ТВ-бокс.
- Хотя бы один прокси-сервер (данные предоставляет ваш провайдер прокси/VPN).
- Телефон с установленным Stealtify — **настоятельно рекомендуется**: это самый
  простой способ перенести конфигурацию, не вводя ничего пультом. См.
  [Перенос конфигурации с телефона](TV_USER_GUIDE.ru.md#2-перенос-конфигурации-с-телефона).
- Язык интерфейса: русский.

Мобильная версия Stealtify **не мешает** телевизионной: у них разные
идентификаторы приложения, они обновляются независимо и могут стоять на одном
устройстве одновременно.

## Какую сборку скачивать

В отличие от телефонной версии, для приставок публикуется **четыре файла**.
Приставки бывают и 64-битные, и 32-битные, поэтому важно выбрать правильный.

| Файл | Для чего |
|------|----------|
| `Stealtify_<версия>-tv_arm64-v8a.apk` | Большинство современных приставок (64 бита) |
| `Stealtify_<версия>-tv_armeabi-v7a.apk` | Приставки с 32-битной системой |
| `Stealtify_<версия>-tv_x86.apk` | Эмулятор Android TV (для разработчиков) |
| `Stealtify_<версия>-tv_universal.apk` | Универсальный: подходит везде, но **примерно вдвое больше** |

**Не знаете разрядность?** Берите `universal` — он гарантированно установится.
Если хочется сэкономить место, определить разрядность можно так:

- Приложение **AIDA64** или **CPU-Z** из Google Play на приставке → раздел «ЦП» /
  «System» → строка с ABI: `arm64-v8a` или `armeabi-v7a`.
- Либо с компьютера, если подключён ADB (см. [Способ 2](#способ-2-adb-с-компьютера)):

  ```powershell
  adb shell getprop ro.product.cpu.abi
  ```

Установили не тот файл — Android откажет с ошибкой вида «Приложение не
установлено» или «Пакет несовместим». Ничего страшного: скачайте `universal`.

## Установка

На Android TV нет привычного файлового менеджера и браузера, поэтому установка
отличается от телефонной. Выберите любой из трёх способов.

### Способ 1 — приложение Downloader (проще всего, без компьютера)

1. На приставке откройте **Google Play** и установите приложение **Downloader**
   (разработчик AFTVnews) — бесплатное, есть на большинстве Android TV.
2. Запустите Downloader и в поле адреса введите пультом ссылку на APK.
3. Дождитесь загрузки — установка предложится автоматически.
4. Если система попросит — разрешите **установку из неизвестных источников**
   для Downloader (переключатель появится сразу, с предложением перейти в настройки).
5. Нажмите **Установить**.

> Ввод длинных ссылок пультом — мучение. Если ссылка длинная, используйте
> Способ 2 или 3.

### Способ 2 — ADB с компьютера

Подходит, если приставка и компьютер в одной сети.

1. На приставке: **Настройки → Об устройстве → Сборка** — нажмите 7 раз, пока не
   появится сообщение «Вы стали разработчиком».
2. **Настройки → Для разработчиков** → включите **Отладка по USB** и
   **Отладка по сети** (название зависит от прошивки).
3. Там же посмотрите IP-адрес приставки (или в **Настройки → Сеть**).
4. На компьютере:

   ```powershell
   adb connect 192.168.1.50:5555
   adb install Stealtify_<version>-tv_arm64-v8a.apk
   ```

   Подставьте свой IP и имя скачанного файла. При первом подключении приставка
   покажет запрос — подтвердите его пультом.

### Способ 3 — USB-флешка или сетевой диск

1. Скопируйте APK на флешку с компьютера.
2. Вставьте флешку в приставку.
3. Установите файловый менеджер из Google Play (например, **X-plore File Manager**
   или **File Commander**), откройте флешку и запустите APK.
4. Разрешите установку из неизвестных источников для файлового менеджера.

## Первый запуск

1. Откройте приложение — в лаунчере приставки оно называется «Stealtify TV».
2. Перенесите конфигурацию с телефона: вкладка **Прокси** → значок **«Импорт с
   телефона»** → на экране появится QR-код. Подробно —
   [TV_USER_GUIDE.ru.md](TV_USER_GUIDE.ru.md#2-перенос-конфигурации-с-телефона).
3. На **Главной** нажмите большую кнопку подключения.
4. При первом подключении Android покажет запрос на создание VPN-соединения —
   подтвердите его пультом (кнопка **ОК** / **Разрешить**).

> ℹ️ Если диалог VPN-разрешения не появляется или приложение закрывается при
> нажатии на кнопку подключения — см. [Известные ограничения](#известные-ограничения).

## Проверка целостности файла (по желанию)

К каждой сборке публикуется контрольная сумма SHA-256 — своя для каждого из
четырёх файлов. Сверить её удобнее всего на компьютере перед копированием на
приставку:

```powershell
Get-FileHash .\Stealtify_<version>-tv_arm64-v8a.apk -Algorithm SHA256
```

```bash
sha256sum Stealtify_<version>-tv_arm64-v8a.apk
```

Полученное значение должно совпасть с суммой, указанной для **вашего** файла.
Суммы разных ABI различаются — это нормально.

## Обновления

Приложение проверяет обновления само и скачивает сборку под ABI вашей приставки.
Предложение обновиться появляется на Главном экране и в разделе
**Настройки → Обновления**.

Телевизионная и мобильная версии обновляются по **разным** каналам и не влияют
друг на друга.

## Известные ограничения

Это бета, и часть вещей на приставках ведёт себя иначе, чем на телефонах.

| Ограничение | Что делать |
|---|---|
| **VPN-разрешение не запрашивается.** Отдельные прошивки Android TV идут без системного диалога VPN. | Проверьте **Настройки → Сеть → VPN** на приставке. Если раздела нет — приставка не поддерживает VpnService, приложение работать не сможет. Сообщите нам модель. |
| **Нет QR-сканера.** На приставках нет камеры. | Переносите конфигурацию с телефона по локальной сети или добавляйте прокси по ссылке-подписке. |
| **Нет плитки в быстрых настройках.** На Android TV нет шторки быстрых настроек. | Управляйте подключением из самого приложения. |
| **Нет раздела «Данные» (бэкапы).** Конфигурация приходит с телефона; правила для приложений работают со списком приложений самой приставки. | Перенесите конфигурацию с телефона либо добавьте прокси по ссылке-подписке. |
| **Импорт с телефона заменяет текущую конфигурацию приставки** (прокси, группы, правила). | В ТВ-сборке нет функции резервного копирования — если на приставке уже настроена конфигурация, которую нужно сохранить, не выполняйте импорт поверх неё. |
| **Нет значка в лаунчере после установки.** Некоторые прошивки прячут приложения без TV-баннера. | Найдите приложение через **Настройки → Приложения → Все приложения** и запустите оттуда, либо через строку поиска лаунчера. |
